Connect your AI

Let Claude, ChatGPT, Gemini, Cursor, VS Code Copilot or any AI agent that speaks the Model Context Protocol) make posters, social posts, thumbnails and video reels in Digital Canvas from your own photos and clips. It works on your designs in your Google Drive, looks at what it made, checks it (contrast, overflowing text, safe zones) and exports PNG, PDF, GIF or MP4 to Digital Canvas/Exports. You can open every design here to finish it by hand.

Claude on the web, desktop or phone

  1. Open Settings › Connectors › Add custom connector.
  2. Name: Digital Canvas · URL: https://digital-canvas-p977.web.app/mcp
  3. Click Connect and sign in with the same Google account you use here.

Then ask, for example: “Make an Instagram post for our Friday night market using the photos in my ‘Market 2026’ Drive folder.”

Every app below uses the same address, https://digital-canvas-p977.web.app/mcp, and the same sign-in: the app registers itself, opens a Digital Canvas page that asks you to confirm, then Google sign-in. Nobody pastes a key. The AI gets access only to your Digital Canvas folder (see What it can see).

ChatGPT

  1. In ChatGPT open Settings › Apps & Connectors › Advanced settings and turn on Developer mode (Plus, Pro, Business, Enterprise and Edu; names of the menus change now and then).
  2. Back in Apps & Connectors, choose Create (or Add custom connector).
  3. Name: Digital Canvas · MCP server URL: https://digital-canvas-p977.web.app/mcp · Authentication: OAuth (leave the client ID empty and any OIDC option off; ChatGPT registers itself).
  4. Tick I trust this application, click Create, then confirm on our page and sign in with Google.
  5. In a chat, open + › More › Developer mode and switch Digital Canvas on.

Gemini CLI

gemini mcp add --transport http digital-canvas https://digital-canvas-p977.web.app/mcp

or add it to ~/.gemini/settings.json:

{
  "mcpServers": {
    "digital-canvas": { "httpUrl": "https://digital-canvas-p977.web.app/mcp" }
  }
}

Start gemini and run /mcp auth digital-canvas: a browser opens for sign-in (the CLI listens on a local port; any port works).

Cursor

Settings › MCP › Add new MCP server, or in ~/.cursor/mcp.json:

{
  "mcpServers": {
    "digital-canvas": { "url": "https://digital-canvas-p977.web.app/mcp" }
  }
}

Cursor shows Needs login: click it to sign in.

VS Code (GitHub Copilot agent mode)

Command palette › MCP: Add Server… › HTTP, or .vscode/mcp.json:

{
  "servers": {
    "digital-canvas": { "type": "http", "url": "https://digital-canvas-p977.web.app/mcp" }
  }
}

VS Code asks to sign in the first time a Digital Canvas tool is used.

Codex CLI, Windsurf and others

codex mcp add digital-canvas --url https://digital-canvas-p977.web.app/mcp
codex mcp login digital-canvas

Windsurf: "digital-canvas": { "serverUrl": "https://digital-canvas-p977.web.app/mcp" } in mcp_config.json. Any client that supports remote MCP over Streamable HTTP with OAuth works the same way. A client that only runs local (stdio) servers can use the local server below, or bridge with npx mcp-remote https://digital-canvas-p977.web.app/mcp.

Agents on OpenRouter (or any model API)

OpenRouter, Groq, Together and similar services sell model access; they don't run MCP servers for you. Use an agent or chat app that is an MCP client (any of the above, or your own code with an MCP SDK) and point it at OpenRouter for the model and at https://digital-canvas-p977.web.app/mcp for the tools. For scripts with no browser, run the local server (npx @digital-canvas/mcp; it signs in once in your browser).

Let AI use your device

With the connector above, the work (opening your designs, rendering previews, exporting PNG, PDF and MP4) happens on one of your own devices, not on our servers. Our server only passes the AI's requests to your device and the answers back.

  1. Open Digital Canvas on a computer or phone, signed in with the same Google account.
  2. Go to File › Settings › AI and devices (on the home page: AI) and turn on Let AI use this device.
  3. Keep it open while the AI works. A small “AI is working on this device” sign shows when it is busy.

Several devices on? The AI asks you which one to use (or pick one in the same panel). If none is on, it tells you to open Digital Canvas.

  • Computer (browser or installed app): works while the tab or window is open; a visible window answers fastest because browsers slow down background tabs.
  • Android app: keeps working in the background while the switch is on (Android shows a notification).
  • iPhone and iPad: only while Digital Canvas is open on screen. iOS pauses apps in the background.

Some accounts can choose cloud processing in the same panel instead: then our server does the work and no device needs to be open.

Claude Code

claude mcp add --transport http digital-canvas https://digital-canvas-p977.web.app/mcp

or run it on your computer (opens the browser to sign in the first time):

claude mcp add digital-canvas -- npx -y @digital-canvas/mcp

Claude Desktop and other apps (local)

Add this to the app's MCP config (Claude Desktop: claude_desktop_config.json):

{
  "mcpServers": {
    "digital-canvas": { "command": "npx", "args": ["-y", "@digital-canvas/mcp"] }
  }
}

The local server always runs on your computer, so it needs no device switch. Work on a folder on your computer instead of Google Drive: "args": ["-y", "@digital-canvas/mcp", "--store", "folder", "/path/to/Designs"]. Video export on your computer needs ffmpeg.

AI inside the editor (your own keys)

The other direction: the editor's AI panel (Design for me, Magic Write, alt text, Generate image, Generate video) runs on the model you choose. Open AI › AI providers (the key button) and add a key for Anthropic (Claude), OpenAI (GPT, GPT Image, Sora), Google Gemini (Gemini, Nano Banana, Omni Flash video), OpenRouter (hundreds of models), kie.ai (Nano Banana, Seedream, GPT Image, Imagen, Grok Imagine, Kling) or any OpenAI-compatible endpoint (Groq, Together, Mistral, DeepSeek, Ollama or LM Studio on your computer). Then pick a default model for writing, designs, vision, images and video.

Keys are kept in this browser only and each is sent only to its own provider. Generated pictures and clips go into your Uploads with the model and prompt that made them.

What it can see

Only your Digital Canvas folder and the files the app created, you opened with it, or you picked in Uploads › Google Drive › Choose from Google Drive. Nothing else in your Drive. To let the assistant use more photos or videos, pick them there. Remove access any time at Google account › Third-party access.
