Digital Canvas (ORCH-27, round r12). Generated by node tools/qa/build.mjs from tools/qa/sharing-cases.mjs. Do not edit by hand.

38 automated 10 live · Automated cases run with npx playwright test against an in-memory Google Drive that models two users (owner and recipient: separate tokens, per-file permissions, 404 for files drive.file has not granted) and a stand-in Google Picker (e2e/fake-drive.ts, e2e/fake-picker.ts). Live cases need real Google accounts.

Before the live cases: the API key used to read pictures of shared designs (DRIVE_API_KEY = the Picker key) must allow the Google Drive API (Cloud console › Credentials › API restrictions). Until then a recipient sees blank placeholders where the owner’s pictures are (QA-43). Drive “Open with” needs the new drive.install scope: new sign-ins ask for it; existing accounts get a one-time “Show in Drive” banner (QA-21, QA-47).
